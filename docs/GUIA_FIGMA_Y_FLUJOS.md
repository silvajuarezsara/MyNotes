# Guía para el prototipo Figma — MyNotes

## Pantallas mínimas
1. Inicio: encabezado, búsqueda, lista de notas y botón flotante.
2. Nueva nota: título, contenido, adjuntar imagen y guardar.
3. Editar nota: datos precargados y actualización.
4. Visor de imagen: imagen a pantalla completa y gesto de zoom.
5. Estados: vacío, nota completada y confirmación de eliminación.

## Flujo principal
Inicio -> botón + -> Nueva nota -> Guardar -> Inicio actualizado.

## Flujo de edición
Inicio -> seleccionar editar -> Editar nota -> Guardar cambios -> Inicio actualizado.

## Flujo de eliminación
Inicio -> deslizar tarjeta -> mostrar acción eliminar -> confirmar visualmente la salida.

## Flujo de imagen
Nueva/Editar nota -> adjuntar imagen -> seleccionar fotografía -> mostrar miniatura -> abrir visor -> pellizcar para ampliar/reducir.

## Especificación visual sugerida
- Color primario: #283593.
- Fondo: #F5F5F5.
- Texto principal: #263238.
- Acento de éxito: #2E7D32.
- Error/eliminar: #B3261E.
- Tarjetas con esquinas redondeadas y separación consistente.

Verificar contraste real entre cada combinación de texto y fondo con una herramienta de accesibilidad.
